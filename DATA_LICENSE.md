# Data License Policy

The default target license for original dataset entries in this repository is **CC0-1.0**.

## Scope

This policy applies to dataset entries, including:

- text art strings
- context examples
- meanings
- plain-text paraphrases
- labels
- display metadata
- review metadata

## Accepted source types

Preferred:

- original entries created by contributors
- entries with explicit permission compatible with this repository
- public-domain or CC0-compatible material with clear provenance

Not accepted by default:

- copied forum posts without permission
- copied social media posts without permission
- copied proprietary text-art collections
- uncertain-license archives
- entries containing private or identifying information

## Code and documentation

Code and documentation may use separate licenses later. Until then, repository text should be treated conservatively and reused according to the license files present in the repository.

## Contributor statement

By contributing an entry, contributors should confirm that they have the right to submit it under the dataset license.
