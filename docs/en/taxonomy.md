# Taxonomy

## Text-art classes

| Value | Meaning | Examples |
|---|---|---|
| `ascii_7bit` | Text art made only from 7-bit ASCII characters | `:-)`, `/\_/\\` |
| `ansi_art` | Text art assuming ANSI escape sequences or color styling | ANSI BBS-style art |
| `shift_jis_style` | Shift_JIS-style text art associated with Japanese forum culture | Large Japanese AA, character-based AA |
| `kaomoji` | Face-like text expression | `(｀・ω・´)`, `m(_ _)m` |
| `unicode_text_art` | Text art using Unicode symbols, box drawing characters, or full-width symbols | `╭( ･ㅂ･)و` |
| `single_line_symbol` | Single-line symbolic expression | `orz`, `XD`, `www` |
| `multi_line_text_picture` | Multi-line text picture | Cat, building, person, object |

## Character-set classes

| Value | Meaning |
|---|---|
| `ascii_7bit` | Primarily U+0000 to U+007F ASCII |
| `extended_ascii_or_ansi` | Extended ASCII or ANSI display assumptions |
| `shift_jis` | Shift_JIS display assumptions |
| `unicode_text` | Contains Unicode characters |
| `mixed` | Mixed character-set or display assumptions |
| `unknown` | Not yet verified |
