# レビュー基準

## 目的

この文書は、投稿されたテキストアート項目を、学習・評価データとして採用できるか判断するための基準を定義します。

## レビュー観点

| 観点 | 確認内容 |
|---|---|
| ライセンス | 投稿者が再配布可能な権利を持っているか |
| 文脈 | 使用例が自然か |
| 意味 | 意味説明が十分か |
| 平文化 | TTSや要約に使える自然文になっているか |
| 表示条件 | 改行・等幅・フォント依存が必要に応じて記録されているか |
| 文化的背景 | 必要な文化ラベルが付いているか |
| JSON構造 | スキーマに一致しているか |
| 安全性 | 個人情報・差別・危険表現が含まれていないか |

## 採用しやすい投稿

- 自作である
- 文脈が自然
- 平文化が明確
- 意味が一意または曖昧性が説明されている
- 表示条件が明記されている

## 採用しにくい投稿

- 出所が不明
- 意味説明がない
- 文化背景が不明
- 表示崩れが大きい
- 単なる文字列のみ

## 推奨レビュー状態

| 状態 | 条件 |
|---|---|
| `draft` | 投稿直後 |
| `needs_review` | 内容確認待ち |
| `reviewed` | 採用済み |
| `rejected` | 不採用 |
| `deprecated` | 非推奨 |
