# 投稿規則

## 基本方針

このリポジトリは、テキストアートを単に集める場所ではありません。学習・評価データとして再利用できるように、意味・文脈・平文化・表示条件を付けて整理します。

## 投稿できるもの

- 投稿者が自作したテキストアート
- 明示的に許諾を得たテキストアート
- CC0または互換ライセンスで提供できるデータ
- 短い一般的表現に、投稿者自身が文脈・意味・平文化を付けたもの

## 投稿しないもの

- 掲示板・SNS・Webサイトから無断コピーしたAA
- 出所やライセンスが不明なAA集
- 実在個人を特定できる情報を含むもの
- 差別・嫌がらせ・性的・暴力的表現を無審査で含むもの
- 意味や文脈が付いていない単なる文字列

## 必須フィールド

各データには最低限、以下を含めてください。

| フィールド | 説明 |
|---|---|
| `id` | 一意のID |
| `art` | テキストアート本体 |
| `art_type` | 種類。例：`ascii_7bit`, `kaomoji` |
| `charset_class` | 文字集合分類 |
| `line_count` | 行数 |
| `context_text` | 使用される文脈例 |
| `intended_meaning` | 意図された意味 |
| `plain_text` | 自然文への平文化 |
| `display_requirements` | 表示条件 |
| `source_type` | `original` など |
| `license` | 例：`CC0-1.0` |
| `review_status` | `draft`, `reviewed` など |

## 品質基準

良い投稿は、次を満たします。

1. 文字列だけでなく、意味が説明されている。
2. 文脈例が自然である。
3. 平文化が読み上げや要約に使える。
4. 文化的背景や表示条件が必要に応じて記録されている。
5. ライセンス上の再利用可能性が明確である。

## レビュー方針

初期段階では、`data/samples.jsonl` に小さな例を追加し、スキーマと分類が安定してから `data/reviewed/` に移します。

不明点がある投稿は、採用ではなく `draft` または `needs_review` として扱います。
